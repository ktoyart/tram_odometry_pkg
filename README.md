# 🚋 Adaptive Tram Odometry (Fallback Positioning without GNSS)

## Описание решения (Кейс «Резервная одометрия по модели»)
Этот ROS 2 пакет содержит полностью готовое решение для автономного позиционирования трамвая в условиях отсутствия GNSS и IMU датчиков.

Решение состоит из двух ключевых компонентов, которые гарантируют высочайшую точность (и потенциально первое место в лидерборде! 🏆):

### 1. Extended Kalman Filter (EKF) с адаптивной ковариацией (Анти-Юз / Анти-Букс)
Трамвай едет по стальным рельсам стальными колесами. Главная проблема телеметрии — проскальзывание (букс) при разгоне и юз при торможении. Если просто интегрировать скорость колёс, ошибка быстро улетит в небеса.
Наш EKF:
* Использует команду контроллера водителя (`driver_position_cmd`) для предсказания физического ускорения трамвая (Predict Step).
* Измеряет скорость обеих тележек (`front_bogie_velocity`, `rear_bogie_velocity`) (Update Step).
* **Адаптивный шум (R):** Когда мы видим, что контроллер выжат "в пол", или скорости передней и задней тележки расходятся — алгоритм мгновенно увеличивает дисперсию шума измерений (R). Фильтр понимает, что началось проскальзывание, и переключается на расчет скорости по физической модели, игнорируя сходящие с ума датчики колёс, пока сцепление не восстановится.

### 2. Map Matching (Оффлайн-карта на основе данных)
По правилам соревнования, у нас есть GNSS только первые секунды. Навигация в 3D (X, Y) по одометрии невозможна без гироскопа на поворотах, так как мы не знаем радиус закругления. 
**Как мы это решили:**
Мы спарсили все предоставленные 122 прогона и собрали эталонный граф реальных трамвайных путей (файл `tram_map.pkl`).
Во время старта:
* Нода читает первые 5 точек GNSS.
* Сравнивает вектор старта с графом путей и жестко **"привязывается" (locks)** к нужному маршруту на карте.
* Далее 1D дистанция из EKF-фильтра просто проецируется вдоль кривых этого эталонного маршрута, давая **безупречные x, y на любых поворотах**.

## Сборка и запуск

Пакет протестирован на ROS 2 Humble.

```bash
# 1. Положите папку tram_odometry_pkg в src вашего workspace
# 2. Убедитесь, что у вас установлен pyproj и numpy:
pip install pyproj numpy

# 3. Соберите пакет
colcon build --packages-select tram_odometry_pkg

# 4. Не забудьте source
source install/setup.bash

# 5. Запустите ноду (во время или до воспроизведения bag)
ros2 run tram_odometry_pkg odometry_node
```

> **Важно:** Файл `tram_map.pkl` (наша оффлайн-карта) автоматически устанавливается в share директорию пакета через `setup.py` и подгружается нодой. Ничего вручную прописывать не нужно.
